How to Use This Screen

Review an analyzed requirement or create one directly, refine its content and prepare it for the next BAForge AI step.

  • Review or enter the requirement title and description.
  • Select the requirement type and priority.
  • Check the quality scores and refine the analysis details.
  • Review ambiguities, missing information, assumptions and business rules.
  • Save the requirement when it is ready for the workspace.
  • Continue to User Story when the requirement is ready.

Tip: You can start directly from this screen even when no requirement has been loaded from Requirement Intelligence.
